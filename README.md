# Willowstration 📚

One of my first JavaScript projects. A landing page for a fictional writing platform, built with plain HTML, CSS and JS. No frameworks.

Working on this taught me how to actually think in JavaScript. Event delegation, the Intersection Observer API, building a modal from scratch, managing state for a slider. It's the project that gave me the foundation everything else I've built is standing on. The credit for this really goes to [Jonas Schmedtmann](https://www.udemy.com/user/jonasschmedtmann/) on Udemy.

Live: [faneeshh.github.io/Willowstration](https://faneeshh.github.io/Willowstration/)
