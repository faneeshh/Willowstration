# Willowstration

*Where Writing Embraces Simplicity*

This was one of my first real JavaScript projects. I built it as a marketing landing page for a fictional writing platform, and it ended up being the project that gave me a solid foundation in vanilla JS — DOM manipulation, event delegation, the Intersection Observer API, and how to structure a page that actually feels interactive. A lot of the patterns I picked up here have carried over into everything I've built since.

No frameworks, no build tools — just HTML, CSS, and JavaScript.

---

## Demo

Live: [https://faneeshh.github.io/Willowstration/](https://faneeshh.github.io/Willowstration/)

---

## What's on the page

- Sticky navigation with a fade effect on hover
- Smooth scroll to sections
- Tabbed content panel
- Lazy-loaded images using Intersection Observer
- Section reveal animations on scroll
- Testimonial slider with keyboard and dot navigation
- Sign-up modal

---

## Built with

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Poppins — Google Fonts

---

## Running locally

```bash
git clone https://github.com/faneeshh/Willowstration.git
cd Willowstration
```

Then just open `index.html` in a browser. No installs needed.

